# 🌩️ Storm Sensitivity

**Smart Free Fire Sensitivity & DPI Generator**

Storm Sensitivity generates personalized Free Fire sensitivity settings based on:

* 📱 Phone model
* 💾 RAM
* 🎚️ DPI
* 🔄 Refresh rate
* 👆 Finger layout
* 🎯 Play style

## ✨ Features

* 📚 Built-in phone database
* ✏️ Manual phone mode
* 🎚️ DPI recommendations
* 🎯 General sensitivity
* 🔴 Red Dot sensitivity
* 🔭 2x Scope
* 🔭 4x Scope
* 🎯 Sniper Scope
* 👀 Free Look
* 🔄 Aim feedback adjustment
* ⚡ Device match score
* 🌑 Dark purple interface

## 🚀 How to use

1. Download `StormSensitivity.exe`
2. Open the application
3. Select your phone brand and model
4. Enter/check your DPI
5. Select your RAM
6. Choose your finger layout
7. Choose your play style
8. Click **Generate Sensitivity**
9. Test the settings in Free Fire
10. Use the **Aim Feedback** buttons to fine-tune the settings
